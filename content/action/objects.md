You can often see objects on trees which are not supposed to be there.
Like lamps, advertisement, alerts or cables, which are fixed to the tree using nails or screws.
This is wrong.
The law on green zones forbids that.

Please reports such cases using the *Active Citizen* app.
We have a very positive experience cleaning up trees from all kinds of objects.
Normally the request is handled within 24 hours, even though a response can be delivered a few days later.
