## Technical SEO status

Applied in this repository:

- **Canonical tags** added for every page and section (`partials/seo.html`).
- **hreflang + x-default** added for `en` / `ru` / `hy` across all translations.
- **Meta descriptions** resolved via `page.description` → `page.summary` → auto excerpt from rendered content (`partials/page-cards.html`).
- **Open Graph / Twitter cards** now emit type, title, description, URL and image.
- **JSON-LD**: `Organization` on every page, `Article` on dated pages (`partials/structured-data.html`).
- **sitemap.xml / robots.txt** are generated by Zola; confirm both are submitted and crawlable in Search Console.

Remaining, editorial (not automatable):

- Add a hand-written `description` to important pages — auto excerpts are a fallback, not a substitute.
- Fix cannibalisation by consolidating or cross-linking competing pages.
