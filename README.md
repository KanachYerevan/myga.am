# Kanach Yerevan website

This repo contains the source code for the Kanach Yerevan website.

The website is a static HTML site built with [Zola](https://getzola.org/).
The built site is deployed to Cloudflare Pages.


## Making Changes

1. Pull this repository.
2. [Install Zola](https://www.getzola.org/documentation/getting-started/installation/).
3. Start Zola in dev mode by running `make serve`.
4. Make changes to the files.


## Folder Strucutre

- `content`: source code for all pages.
- `data`: YAML based data files for some sections.
- `docs`: additional documentation on how the site works.
- `static`: images, documents and other static files.
